# TechHive

A student community platform for our department, with secure login, an announcements dashboard, and real-time study channels.

## Features
- Login with registration number and password
- Dashboard with announcements and study channels
- Real-time chat per channel (Socket.io)

## How to run
1. Clone the repo
2. Run `npm install`
3. Run `node server.js`
4. Open http://localhost:3000
